# About this archive

This site is a preserved copy of the **fxhash documentation**, which was published at `docs.fxhash.xyz` using GitBook. It was rebuilt from the Internet Archive's [Wayback Machine snapshot of 13 March 2026](https://web.archive.org/web/20260313230640/https://docs.fxhash.xyz/) and is kept online as a portfolio sample by [Gorilla Sun](https://www.gorillasun.de/).

It is not the official fxhash documentation and is not maintained by fxhash. The content has been kept as it was published at the time of the snapshot.

## What's included

All 71 pages from the documentation's navigation, organised as they were on the original site:

- **Docs Overview** and **Quickstart Guide**
- **Creating on fxhash**: project setup and the fxhash CLI, the `$fx` API and fx(params), open-form generative art, generative art in the browser, and releasing a project
- **Collecting on fxhash**: the platform overview and collector tips
- **Knowledge Base**: fxhash & Web3 fundamentals, onboarding, and policies & guidelines
- **ONCHFS**: the on-chain file system used to store projects

Page addresses mirror the original site. For example, `docs.fxhash.xyz/creating-on-fxhash/fxhash-api/api-reference` corresponds to `creating-on-fxhash/fxhash-api/api-reference/` here.

## How it was restored

- 65 pages come from captures made between 10 and 13 March 2026. The *Collector's Code of Conduct* comes from 17 February 2026, the closest capture available. Five pages come from 11 April 2026, where the archive had stored GitBook's Markdown source instead of the rendered page.
- Every page ends with a link to the exact Wayback Machine capture it was restored from.
- Images were recovered at full resolution from GitBook's file storage and optimised for the web. Two small interface screenshots on the *Minting Interface Walkthrough* page were never archived and are marked as missing.
- Interactive CodePen demos and the YouTube video are embedded live from their original sources.
- A few formatting quirks of the original pages, such as some literal asterisks and a stray `<aside>` tag, are shown exactly as they were published.
